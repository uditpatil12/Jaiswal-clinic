## Deploy on GitHub Pages
1. Create a repository named `uditpatil12.github.io` (or use your GitHub username plus `.github.io`).
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. The site will be available at `https://uditpatil12.github.io/` after GitHub Pages finishes publishing.
